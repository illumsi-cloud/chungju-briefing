# 충주 동향 브리핑 대시보드 (Chungju Regional Briefing)

충주시의 개발, 부동산, 학교 신설 및 관련 지역 여론을 자동으로 수집하여 직관적인 단일 웹페이지로 제공하는 모니터링 대시보드입니다.

지역 내 대규모 공동주택 신축, 분양 전환, 도시계획 변경 사항 등은 향후 학생 배치 계획 및 통학 구역 설정 등 핵심 행정 업무와 직결됩니다. 산발적으로 흩어져 있는 관공서 공고와 지역 내 주요 커뮤니티 여론을 매일 자동으로 취합하여, 실무 현장에서의 정보 수집 동선을 단축하고 행정 업무의 효율성을 높이기 위해 개발되었습니다.

[🔗 대시보드 바로가기](https://illumsi-cloud.github.io/chungju-briefing/)

---

## ✨ 주요 기능

*   **100% 자동화된 파이프라인:** GitHub Actions를 활용해 매일 3회(10:00, 14:00, 17:40) 파이썬 수집 스크립트가 실행되며, 변경된 결과물이 GitHub Pages를 통해 즉시 배포됩니다.
*   **스마트 필터링 및 그룹화:** 동일한 이슈를 다루는 여러 매체의 유사 뉴스 기사를 대표 1건으로 묶어(Bigram 유사도 분석) 정보의 중복을 방지합니다.
*   **위기 징후 즉시 감지:** 제목과 요약본에 특정 주의어(예: 부도, 공사 중단, 법정관리, 보증금 반환 지연 등)가 포함될 경우, 즉각적으로 🚨 주의 배지를 부여해 리스크에 선제적으로 대응할 수 있습니다.
*   **안전한 캐시 복구 시스템:** 관공서 서버 방화벽이나 응답 지연(Timeout)으로 인해 일시적으로 데이터 수집에 실패하더라도, 직전 성공 데이터를 불러와 대시보드의 화면 레이아웃이 무너지는 것을 방지합니다.
*   **신규 데이터 하이라이트:** 이전 수집 이력(`item_history.json`)과 비교하여 최초로 발견된 항목에는 '신규' 배지를 노출합니다.

## 📡 데이터 수집 출처

*   **충주시청:** 공지사항, 입법예고, 고시/공고/입찰 (지정된 관련 부서 필터링 적용)
*   **국토교통부 통합 시스템:** 토지이음(eum.go.kr) 도시계획 고시 정보
*   **주택도시보증공사(HUG):** 보증사고 및 반환 지연 관련 1차 민원 데이터
*   **자치법규정보시스템(elis.go.kr):** 충주시 및 충청북도 도단위 입법예고
*   **네이버 API (뉴스 및 카페):** 주요 지역 맘카페 및 부동산 커뮤니티 핵심 키워드(분양, 학군, 과밀학급 등) 모니터링
